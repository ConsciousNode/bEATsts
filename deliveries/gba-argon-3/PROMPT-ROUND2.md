# bEATsts GBA, round 2: draw everything the reference draws

Same spec as round 1 (`PROMPT.md`, `GBA-RULES.md`). Kehai's audit of your delivery is attached (`AUDIT.md`).

**What passed.** Your game logic is a faithful port. An input-only fuzz (4,400 random presses) and mGBA (148 checkpoints) both agree with the reference. Keep all of that.

**What's missing.** A person can't play it. Only map-name banners draw text. There's no OBJ layer: the player is a yellow block and NPCs are invisible. Species sprites carry stray tiles. And REPORT §1 says all of this is rendered.

## Fix
1. **Rendering.** Draw every screen the reference draws, the same way it draws it:
   - title, slots and name entry;
   - dialogue, with paging;
   - the overworld, including the player, NPCs and trainers as OBJs with facing and walk frames;
   - battle: both sprites, names, levels, HP bars, Kitchen Temp, the main/fight/plate/bag/party menus and the log;
   - the menu, bEATdex, party, box, bag, shop, learn-move, options, controls and credits screens.
   - Species sprites must show index 0 as transparent.
2. **Dex bitmaps.** Read and write them only with byte access, or 4-align them. This fixes the mailbox dex and Brotholomew's 151/151 check, which must read all 151 caught bits and nothing else.
3. **Tests.** Tests may touch the ROM **only** through `setKeys`, the mailbox and a `.sav` file (loaded as SRAM before boot). Remove every write to EWRAM, IWRAM, IO or VRAM from `tests/`. Rebuild the battle and audio tests to reach their states by playing.

## New test: pixel differential (the main instrument)
- The reference draws only with `fillRect` and bitmap fonts, onto a 240×160 canvas.
- Run it in headless Chromium.
- After every press in the overworld bot replay and in the quest replay:
  - wait until the mailbox says "accepting input", then run 4 idle frames;
  - compare the ROM framebuffer to the reference canvas.
- **Color rule:** quantize each reference pixel to 5 bits per channel, then compare it exactly with the ROM's BGR555 value.
- **Report:** matching pixels per screen type, the 20 worst frames as side-by-side PNGs, and a list of every frame that differs, with the reason.
- **Animation:** where the reference animates on a timer (credits scroll, transitions), say so and compare at the same timer value. Don't skip the frame.
- **Positive controls (each must fail):**
  - a ROM whose font table is shifted by one glyph;
  - a ROM with the OBJ layer disabled;
  - a ROM whose battle HP bar draws one pixel short.
- Also:
  - add the dex bitmaps (seen and caught) to the per-press mailbox comparison in Test 4;
  - add a Brotholomew test: a real 151-caught `.sav` from `html-save-to-sav.py` must show the diploma dialogue, and a 150-caught `.sav` must show the normal lines.
